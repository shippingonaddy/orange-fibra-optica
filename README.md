# ORANGE — Fibra Óptica & Telecomunicaciones
### WPN IMPORTADORES S.A.S. (Guayaquil, Ecuador)

Sitio web institucional y catálogo B2B mayorista para redes FTTH en Ecuador:
- **Líneas de producto**: Bobinas marca ORANGE (Drop G657A2, ADSS, ASU, Figura 8), Cajas NAP IP68, ODF, Splitters PLC, Fusionadoras Signal Fire AI9, Mini OTDR, Chasis OLT Huawei MA5800.
- **Stack**: HTML5 semántico, CSS responsivo moderno, JavaScript modular (Canvas 60fps con pulso de luz óptica), micro-interacciones interactivas, Schema.org `WholesaleStore` JSON-LD, optimización Core Web Vitals y diseño adaptado a móviles con dock directo de llamada y WhatsApp.
